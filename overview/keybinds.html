    Decided 20 November

    1. Reply to whisper on Ctrl + R (replaces the framerate toggle).
    2. Sheathe weapon on Ctrl + Z, sit / swim down on Ctrl + X.
    3. The main action bar sits on § 1–5 Q E R F T G on every character, so those keys swap with Meagor's stealth bar and Galdorin's stances. Keys 6–0 are unbound.

    Setting it in game

    The WyldKeys addon applies this layout: /kb setup once (learns what the game calls §), then /kb preview and /kb apply on each character. /kb restore undoes it. Shift keys, Z and X use Action Bar 2; Ctrl + 1–3 use Action Bar 3. Healing potion is on Shift + Q for every character. Interrupt is on E for every character; the mouse side buttons are not used for now, because Logi Options+ only sends them on release.

    The character views are generated from the addon’s Config.lua (overview/build.lua in the WyldKeys repository), so they match what /kb apply sets.
